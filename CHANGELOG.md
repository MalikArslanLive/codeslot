# Changelog

## 1.0.0

Initial public release of CodeSlot:

- Site-wide and individual Header, Body and Footer fields for pages, posts, products, public custom post types and term archives.
- PHP, JavaScript, CSS, HTML, text, reusable content and shortcode snippets, with priorities, schedules, devices and automatic/manual insertion.
- Searchable conditions, AND/OR groups, exclusions and declared plugin dependencies.
- Snippet organization, native Screen Options, Quick/Bulk Edit, inactive duplication, Trash/Restore and locks.
- Change-only saved versions with previous/current code comparison and inactive restoration.
- JSON file import/export and full CodeSlot backups, with duplicate detection, protected replacement choices and detailed section-wise notices.
- Optional head-loaded conversion integrations, independent GA4/Ads settings and authorized WooCommerce commerce events.
- Static JavaScript/CSS delivery, JavaScript compaction, 142 local recipes, virtual public files and private diagnostics.
- Capability/nonce checks, bounded validation, Safe Mode, best-effort PHP recovery and opt-in uninstall cleanup.
- WordPress.org readme, beginner/advanced guides, eight actual interface screenshots, icons and banners.
