# Contributing

Use GPL-compatible original code and preserve unrelated changes. Keep plugin source, documentation and version metadata consistent. Do not commit dependencies, database dumps, credentials, private snippets or proprietary software.

Use the local commands in [Development](docs/DEVELOPMENT.md) and [Testing](docs/TESTING.md) to validate changes. Add regression coverage for isolation, authorization and recovery defects. Describe actual results accurately; privileged PHP is not a sandbox.

Report reproducible defects using the issue template. Report vulnerabilities privately as described in [Security](SECURITY.md).
