# Local snippet library

CodeSlot includes 142 original recipes and configuration guides. Search by name, filter by category, preview code and browse paginated cards directly in WordPress.

Executable recipes open as inactive drafts. Review the code and example values, save the snippet and deliberately enable it. Categories cover content, administration, editor settings, login, media, comments, RSS, SEO, design, email, shortcodes, privacy, security and performance.

Three configuration guides explain settings that belong in wp-config.php before WordPress loads. These cards display the code and setup instructions. Follow the instructions with a backup and filesystem access.

PHP recipes that register early filters use the bootstrap location at init. This location supports all request types and has no query conditions. Query-ready snippets continue to support conditions and individual placement.

The library is bundled locally and works without an external account. Each executable recipe's schema, syntax and inactive default are checked in real WordPress integration. Review theme compatibility and configuration before activation.
