# GitHub repository settings

- Description: Free WordPress code manager with global and individual code slots, snippets, conditions, recovery, virtual files and conversion pixels.
- About website: https://malikarslan.com/
- Topics: wordpress, wordpress-plugin, code-snippets, php, javascript, css, woocommerce, gutenberg, elementor.
- Plugin URI: https://github.com/MalikArslanLive/codeslot
- WordPress.org listing URL: https://wordpress.org/plugins/codeslot/

The owner verified the settings through GitHub's interface. Both main and develop require a pull request, resolved conversations and up-to-date GitHub Actions checks named `package` and `dependencies`. Force pushes and branch deletions are blocked. The repository administrator retains emergency bypass and no second approval is required for a solo maintainer.

Automatic deletion of merged head branches, private vulnerability reporting, the dependency graph, Dependabot alerts and Dependabot security update pull requests are enabled. Secret scanning push protection was already enabled. The workflows do not deploy to an environment.

See [GitHub Releases](https://github.com/MalikArslanLive/codeslot/releases) for release status and [TEST-REPORT.md](TEST-REPORT.md) for validation.
